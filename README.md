# MultiStream

A web-based multi-streaming platform with real-time watch rooms, unified Twitch/Kick chat, and interactive 2D/3D viewing modes. Powered by **Firebase Realtime Database** (Spark Free Tier).
<img width="499" height="336" alt="image" src="https://github.com/user-attachments/assets/e6143e6c-190b-464a-a753-1dc2f4eeb44e" />
## Features
- **Multi-Platform Streams:** Watch multiple Twitch and Kick streams simultaneously in a single interface.
- **Synchronized Watch Rooms:** Create a room and share an invite link. Only the host controls the stream list and layout, while viewers stay fully synchronized.
- **Synced Chat States:** Toggling or switching the chat panel as a host automatically mirrors the state for all viewers in the room.
- **2D & 3D Viewing Modes:** Switch seamlessly between a classic 2D grid layout and an interactive 3D room featuring a retro TV setup.
- **Zero-Cost Backend:** Built on Firebase Realtime Database and Authentication, running smoothly within the free Spark plan limits (up to 100 concurrent connections).
